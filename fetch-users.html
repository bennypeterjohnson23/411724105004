User Directory

Click the button to load users from the internet!

HTTP Methods

POST — Create a new user

URL: https://jsonplaceholder.typicode.com/users

{ "name": "Priya", "email": "priya@mail.com", "phone": "9876543210" }

Response: 201 Created

PUT — Replace user #1 (all fields)

URL: https://jsonplaceholder.typicode.com/users/1

{ "id": 1, "name": "Ravi", "email": "ravi@mail.com", "phone": "9123456789" }

Response: 200 OK

PATCH — Update one field of user #1

URL: https://jsonplaceholder.typicode.com/users/1

{ "email": "new@mail.com" }

Response: 200 OK

DELETE — Remove user #1

URL: https://jsonplaceholder.typicode.com/users/1

No body needed. Just send DELETE to the URL.

Response: 200 OK
